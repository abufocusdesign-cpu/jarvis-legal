Privacy policy for Jarvis

Last updated: 22 October 2026

Jarvis is a personal assistant used only by its owner. It is not available to the public. This page explains what the app does with Google data.

What Jarvis accesses

When the owner signs in with Google, Jarvis may use these permissions on the owner's own account only:

  • Gmail: read email, and send email to the owner (for example a daily summary).
  • Google Calendar: read, create and change the owner's events.
  • Google Docs: create and format documents.
  • Google Drive: find, read, organise and move files to the Drive trash on the owner's request.
  • YouTube: read-only search for public video information.

How the data is used

The data is used only to carry out the owner's own requests and automations. It is not used for advertising, is not sold, and is not shared with any other person or company. No human other than the owner reads it.

Where the data is kept

Sign-in tokens are stored only on the owner's own computer, in a file that is not published or shared. Jarvis does not keep a separate copy of Google data on any public server.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Control and deletion

The owner can remove Jarvis's access at any time at myaccount.google.com/permissions, and can delete the stored sign-in file from the computer.
